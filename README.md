# Insta Smart Laundry Website

Modern, minimalistic, and responsive website built for **Insta Smart Laundry** located in Mahalaxmi Nagar, Indore (4.9★ on Google).

## 🚀 Features
- **Modern Minimalist UI**: Fluid responsive design with vanilla HTML5, CSS3, and JavaScript.
- **Interactive Laundry Price Estimator**: Dynamic pricing by weight (kg) and itemized garment count with direct WhatsApp ordering.
- **Quick 30-Second Pickup Booking**: Direct pickup scheduler formatting instant WhatsApp bookings.
- **SEO & Schema.org Structured Data**: LocalBusiness schema for dry cleaning & laundry services.
- **Service Highlights**: Wash & fold, steam ironing, boutique dry cleaning, blanket/quilt care, and specialized stain treatments.
- **Store Location & Hours**: Embedded Google Map, working hours, and covered service areas across Indore.

## 💻 Running Locally
Simply open `index.html` in any web browser, or serve using any static file server:
```bash
npx serve .
```
